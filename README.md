# Vrinda Store Sales Analysis – Excel

## 📊 Project Overview

This project is an Excel-based data analysis project focused on analyzing Vrinda Store's sales and order data.

The objective of this project is to explore sales performance, customer demographics, order status, sales channels, and state-wise sales to identify useful business insights.

## 🛠️ Tools & Techniques

* Microsoft Excel
* Data Cleaning
* Data Analysis
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Visualization
* Dashboard Creation

## 📁 Workbook Contents

The Excel workbook contains multiple analysis sheets:

* **Sales Vs Orders** – Analysis of sales and order trends
* **Vrinda Store Report** – Overall sales performance report
* **Men Vs Women** – Comparison of sales/orders by gender
* **Order Status** – Analysis of delivered, cancelled, returned and refunded orders
* **Top 5 States** – Identification of the top-performing states
* **Age & Gender** – Analysis of customers based on age and gender
* **Channels** – Analysis of different sales channels
* **Vrinda Store** – Source/working data

## 🔍 Key Analysis Areas

The project analyzes:

* Monthly sales and order trends
* Sales performance by gender
* Order status distribution
* Top-performing states
* Customer age groups
* Gender and age-wise purchasing behavior
* Sales performance across different channels

## 📈 Key Insights

The analysis was used to identify patterns in:

* Sales and order volume
* Customer demographics
* State-wise performance
* Channel-wise sales
* Order fulfillment and returns
* Customer purchasing behavior
